# NovaLauncher

NovaLauncher is an independent third-party launcher and client for Minecraft: Java Edition.

Nova is designed to provide users with a modern launcher experience for Minecraft Java Edition, including Microsoft account authentication, Minecraft version management, instances, mods, and launching.

Users authenticate using their own Microsoft account and must already own Minecraft: Java Edition. Nova does not provide Minecraft licenses, bypass ownership checks, or circumvent Microsoft/Minecraft authentication.

The application uses Microsoft's OAuth authentication flow followed by Xbox Live and XSTS authentication and then the official Minecraft Services authentication endpoint.

Nova uses its own Microsoft Entra application registration and Client ID. We are requesting authorization for this Client ID to access the Minecraft Services authentication flow for legitimate Minecraft Java Edition users.

Application name: NovaLauncher
Application type: Windows desktop application
Minecraft edition: Java Edition
